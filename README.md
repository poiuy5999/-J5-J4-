## J4：具身智能机器人从入门到产业应用

J4 作为整套体系的筑基入门课程，目标是帮助零基础或跨专业学习者，低成本建立**感知 - 决策 - 执行**完整机器人开发框架，无需购置昂贵实体机器人，依托咕泡 AI 云实验室，浏览器直接登录即可使用预装 Linux、ROS2、Gazebo 的云端仿真环境，降低入行门槛。

课程开篇夯实机器人底层数学与系统基础，讲解 Linux 操作系统、Shell、Python 编程，学习机器人位姿描述、坐标系变换、正逆运动学、雅可比矩阵，用 Python 动手实现坐标变换与运动计算，理解机器人运动底层原理。随后进入 ROS2 机器人操作系统核心学习，掌握 URDF 机器人建模、TF 坐标变换、RViz 可视化、ROS2 节点通信，搭建 Gazebo 仿真场景，完成移动机器人、机械臂的仿真建模。

感知模块是 J4 的核心实战内容，系统学习相机、激光雷达等传感器原理，学习 OpenCV、深度学习目标检测、语义分割、点云处理，实现多传感器数据融合。学员动手完成环境物体识别、障碍物检测，落地移动机器人自主导航、避障、机械臂物体抓取等仿真项目。课程设置应用型、开发型两条学习路线：应用型适合跨专业转行、产品、运维人员，掌握机器人项目部署、调试运维；开发型面向计算机、自动化、机电专业学员，主攻感知算法、机器人软件二次开发，为 J5 高阶课程做好铺垫。

课程专门设置产业全景板块，跳出单纯算法学习，梳理具身智能产业链上下游，分析人形机器人、四足机器人、工业巡检机器人、服务机器人商业化现状，讲解岗位需求与职业发展路径。课程配套课件、数据集、项目源码、实训脚本，讲师由产业一线机器人工程师授课，配套直播答疑。学员完成 J4 之后，能够独立完成机器人仿真项目开发，看懂产业落地难点，具备进入 J5 高阶课程的基础能力。

课程进阶拓展部分讲解多智能体协同思路，学习将机器人基础感知、导航、抓取能力封装为标准化机器人 Skill，依托 MCP 协议接入 DeepAgents+MCP+A2A+Skills 超级多智能体集群。DeepAgents 下发物理世界任务，通过 A2A 协议完成智能体任务委派，机器人 Skill 可与编码 Skill、质检 Skill 联动，打通数字世界软件研发与物理世界机器人执行的链路，同时配置人在回路审批机制，规避机器人物理操作带来的安全风险。

## J5：具身智能进阶开发工程师课

J5 是 J4 的高阶进阶课程，面向已经掌握 J4 仿真开发基础的学员，聚焦**Sim2Real 仿真迁移、机器人动力学、VLA 视觉语言动作大模型、实体机器人软硬件联调**，解决行业最大痛点：仿真环境效果很好，部署到实体机器人上就失效的仿真现实鸿沟。J5 课程主打企业级工程实战，覆盖 18 个工业真实场景，学习真机控制、强化学习、模仿学习、机器人 Agent 开发，培养能够完成实体机器人二次开发、算法调优的具身智能开发工程师。

课程开篇学习机器人刚体动力学、控制理论，理解关节力矩、惯性、摩擦等真机物理特性，学会设计控制器，弥补仿真环境与真实物理世界之间的差异。重点学习 Sim2Real 迁移方案，讲解仿真域数据采集、域随机化、域自适应算法，把仿真环境训练好的感知、规划模型，迁移到实体机器人，大幅降低真机调试的数据采集成本。随后进入 VLA 视觉语言动作大模型开发，学习视觉语言动作模型原理、多模态数据处理、机器人动作生成，开发具身智能 Agent。当接收自然语言指令，机器人 Agent 可以自主理解任务、规划动作序列、调用感知工具，完成抓取、巡检等物理任务。课程重点强调大模型幻觉风险，搭建人在回路机制，高危物理动作必须人工审批，防止机器人误操作引发安全事故。

课程大量开展真机联调实战，在实训平台操作实体机械臂、移动机器人，完成真实场景下的物体抓取、场景巡检、动态避障，学习真机标定、传感器校准、故障排查、模型性能优化，掌握机器人数据集采集、标注、清洗、模型微调全流程。项目覆盖工业巡检机器人、服务人形机械臂、自主抓取机器人等真实产业场景，项目成果可以直接写入求职作品集。课程邀请行业专家授课，同时开放头部机器人企业内推通道，优秀学员可获得面试推荐机会。

课程后半段进入多智能体集群协同工程化实战。学员学习将真机机器人的感知、动作执行能力封装为 Skill，接入 DeepAgents+MCP+A2A+Skills 超级多智能体集群。DeepAgents 接收顶层任务，通过 A2A 协议进行任务分发，机器人 Skill 可以联动编码 Skill、Harness 质检 Skill、AIOps 运维 Skill，实现需求拆解、软件开发、代码校验、机器人真机部署、物理任务执行一体化自动化流水线。学员学习集群任务调度、异常重试、调用审计、权限管控，掌握多智能体架构的边界设计，避免过度设计。

整套 J4+J5 体系课，完整复刻企业真实机器人项目开发流程，从仿真入门，到真机算法、VLA 模型、Sim2Real 迁移，层层递进。课程适合计算机、自动化、机电工程在校生，以及软件工程师、机器人二次开发人员，想要转型具身智能、人形机器人开发岗位。

完成 J4+J5 整套课程学习之后，学员不再只停留在仿真 Demo 开发，而是具备从仿真建模、感知算法、VLA 智能体开发，到实体机器人部署调试的完整工程能力，能够独立开发、调试工业机器人、人形机器人相关项目。同时理解多智能体集群协同架构，打通数字智能体与物理机器人的联动，抓住人形机器人产业化爆发带来的技术与就业红利。
